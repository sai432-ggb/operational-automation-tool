# VS Code Setup Guide - Complete Step-by-Step Instructions

## Prerequisites

Before starting, make sure you have:
- VS Code installed
-  Python 3.8+ installed
-  Git installed (for GitHub upload)

---

## Step 1: Create Project Folder

1. **Open VS Code**
2. Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac)
3. Type "Open Folder" and select it
4. Navigate to where you want to create your project
5. Click "New Folder"
6. Name it: `operational-automation-tool`
7. Click "Select Folder"

---

## Step 2: Open Integrated Terminal

1. In VS Code, press `` Ctrl+` `` (backtick) or go to **View → Terminal**
2. You should see a terminal at the bottom of VS Code

---

## Step 3: Create Folder Structure

**Copy and paste this into the terminal** (all at once):

### For Windows (PowerShell):
```powershell
# Create all directories
New-Item -ItemType Directory -Force -Path ".github\workflows"
New-Item -ItemType Directory -Force -Path "src\config"
New-Item -ItemType Directory -Force -Path "src\automation"
New-Item -ItemType Directory -Force -Path "src\utils"
New-Item -ItemType Directory -Force -Path "src\models"
New-Item -ItemType Directory -Force -Path "tests\fixtures"
New-Item -ItemType Directory -Force -Path "data\input"
New-Item -ItemType Directory -Force -Path "data\output"
New-Item -ItemType Directory -Force -Path "data\logs"
New-Item -ItemType Directory -Force -Path "docs"
New-Item -ItemType Directory -Force -Path "scripts"
New-Item -ItemType Directory -Force -Path "config"

# Create .gitkeep files
New-Item -ItemType File -Force -Path "data\input\.gitkeep"
New-Item -ItemType File -Force -Path "data\output\.gitkeep"
New-Item -ItemType File -Force -Path "data\logs\.gitkeep"

echo "Folder structure created successfully!"
```

### For Mac/Linux (Bash):
```bash
# Create all directories
mkdir -p .github/workflows
mkdir -p src/{config,automation,utils,models}
mkdir -p tests/fixtures
mkdir -p data/{input,output,logs}
mkdir -p docs
mkdir -p scripts
mkdir -p config

# Create .gitkeep files
touch data/input/.gitkeep
touch data/output/.gitkeep
touch data/logs/.gitkeep

echo "Folder structure created successfully!"
```

## Step 16: Setup Python Virtual Environment

In the **VS Code Terminal**:

### For Windows:
```powershell
# Create virtual environment
python -m venv venv

# Activate it
.\venv\Scripts\Activate.ps1

# If you get an error, run this first:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# Then try activating again
.\venv\Scripts\Activate.ps1
```

### For Mac/Linux:
```bash
# Create virtual environment
python3 -m venv venv

# Activate it
source venv/bin/activate
```

You should see `(venv)` at the start of your terminal prompt.

---

## Step 17: Install Dependencies

With the virtual environment activated:

```bash
# Upgrade pip
pip install --upgrade pip

# Install production dependencies
pip install -r requirements.txt

# Install development dependencies (optional but recommended)
pip install -r requirements-dev.txt
```

Wait for all packages to install...

## Troubleshooting

### Issue: "python command not found"
**Solution**: Use `python3` instead of `python`

### Issue: Can't activate virtual environment on Windows
**Solution**: Run PowerShell as Administrator:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Issue: Import errors when running
**Solution**: Make sure you're in the project root and venv is activated

### Issue: Module not found errors
**Solution**: Reinstall dependencies:
```bash
pip install -r requirements.txt
```
